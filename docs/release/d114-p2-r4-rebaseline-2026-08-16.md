# D114 P2 release line re-baselined to six-row r4 — 2026-08-16

**Archived evidence — do not execute commands from this file.**

The governed D114 P2 baseline moved from six-row keyboard **r2** to **r4**
(modern paged layout). r4 is now a reproducible, governance-tracked
configuration end to end, not a device-local hand-patch. Commit `22c2878`.

## Why

The r4 keyboard was originally only a `lmi-weston-sixrow-clients` build
with no matching `device-xiaomi-lmi-terminal` session package; installing
it on the device removed the r3 session package (exact-version dependency)
and black-screened greetd (recorded in
`notes/d115-persistent-boot-flash-2026-08-15.md`). The owner chose to make
r4 the full governed baseline rather than keep it a hand-patch.

## Device

The connected device was moved off the hand-patched session onto the
governance-built package: `apk add device-xiaomi-lmi-terminal-0.1.0-r4`
now tracks the package (1200 packages), session `8635cf1a…`, greetd
`started`, r4 keyboard `8cb3865b…` running on screen. Persistent boot is
unaffected (boot partition untouched). No reflash and no reboot were
needed — the package session bytes are identical to the verified
hand-patch.

## Unchanged

The r1-frozen and r2 attestations and the r2-era private build artifacts
are retained as historical records (never regenerated in place). Binary
image publication remains blocked by the credential-sanitization gate
(the embedded account password hash) pending the r145 clean rebuild;
this re-baseline changes the keyboard generation, not that gate.
